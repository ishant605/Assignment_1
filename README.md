# Task_1
# Basic Calculator in Python

## Overview
This Python script performs basic arithmetic operations: addition, subtraction, multiplication, and division. The user inputs two numbers, and the program calculates the results.

## Features
- Accepts two user-input numbers.
- Performs:
  - Addition (`+`)
  - Subtraction (`-`)
  - Multiplication (`*`)
  - Division (`/`) (Handles division by zero)
- Displays results in a clear format.

## How to Use
1. Run the script in a Python environment.
2. Enter two numbers when prompted.
3. View the calculated results.

# Task_2
# Greeting Program in Python

## Overview
This Python script prompts the user to enter their first and last name and then displays a personalized greeting message.

## Features
- Accepts user input for first and last names.
- Concatenates the inputs into a full name.
- Displays a friendly welcome message.

## How to Use
1. Run the script in a Python environment.
2. Enter your first and last name when prompted.
3. View the personalized greeting.
